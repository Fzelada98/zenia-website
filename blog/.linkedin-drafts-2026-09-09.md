## DRAFT score=15 — agente-ia-para-academias-de-doblaje

Voice acting schools in Spain lose 41% of inbound leads because the studio director is at the mic when Instagram DMs and WhatsApp messages land.

Built a WhatsApp Business Cloud API agent for that queue. Tool-use loop bound to Google Calendar (director availability), Skedda (studio rooms), Stripe (matriculation payment) and Holded (invoicing). ~6 tool calls per conversation, all persisted to the CRM.

Median first-response is 9 seconds. P99 model latency 680ms, inbound webhook adds ~2s. Voice-test scheduling closes to a signed contract inside the same thread; no separate funnel.

Calendar writes are gated only by an availability check, no human confirm. Double-booking rate at 90 days: 0. Reminder misses: 3 (Meta rate-limit; fixed with a token bucket in front of the message queue).

Room occupancy moved from 63% to 85% in the same window. Full write-up with architecture and per-tool metrics: https://zeniapartners.com/blog/agente-ia-para-academias-de-doblaje.html
